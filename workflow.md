# Sample Workflow

> This describes a generic demonstration flow, not the confidential or verified internal workflow of Varta AI.

## Flow

1. Open the application.
2. Enter valid input.
3. Process the request.
4. Display the response.
5. Compare the observed outcome with the expected outcome.
6. Record any mismatch for review.

## Validation approach

For each step, define an expected outcome and compare it with the observed outcome. A step is marked `PASS` when the values match and `FAIL` when they differ. A workflow passes only when all included steps pass.

## What to customize

If you have permission, replace these generic steps with the actual workflow stages you worked on. Do not include credentials, personal/customer information, proprietary prompts, internal endpoints, or other confidential details.
