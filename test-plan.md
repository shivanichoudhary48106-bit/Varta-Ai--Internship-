# Sample Test Plan

These are example test scenarios for the demo code, not claims about tests executed on the real Varta AI product.

| ID | Scenario | Expected result |
|---|---|---|
| WF-01 | Actual outcome matches expected outcome | PASS |
| WF-02 | Actual outcome differs from expected outcome | FAIL |
| WF-03 | Run the supplied sample workflow | All sample steps pass |
| WF-04 | Review output for a failed step | Expected and actual values are shown |

## Reporting an issue

When testing an authorized system, record:
- Test ID and date
- Preconditions and steps performed
- Expected result
- Actual result
- Reproduction notes
- Status and follow-up

Avoid recording secrets or confidential customer information in a public repository.
